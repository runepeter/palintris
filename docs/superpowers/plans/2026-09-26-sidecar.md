# Lokal spillende sidecar

## Ferdig, avgrensning og verifisering
Ferdig: lokal CLI spiller med ekte Ollama, lager strategi fra erfaring, sammenligner kandidat og incumbent på identiske dev-brett, beholder bare målt forbedring og rapporterer separat holdout. Reproduserbare spor, stopp, tids-/kallgrenser og gjenopptakelse. Ingen endring av modellvekter, spillregler, UI, Vorz eller produksjonsdata; ingen automatisk kildekodeendring/deploy fra modellen.
Verifisering: `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, sidecar-smoke mot faktisk lokal `gemma4:e4b-mlx`, deretter én begrenset komplett iterasjon. Ingen påstand om forbedring uten målte resultater. Browserkontroll dekkes av samme appversjons release-suite; sidecaren er lokal.

## Beslutning
Vorz sin nåværende `ai-agent/src/league/` er egnet referanse. Eldre RL-runner er deaktivert og gjenbrukes ikke. Vi gjenbruker arkitekturmønstre, ikke filer eller runtimeimport på tvers av repoene. Dette er belønningsstyrt prompt-/strategisøk, ikke vekttrening. BFS er evaluator, aldri modellens fasit.

## Kontrakt
- `scripts/sidecar/` bruker faktiske board/step/solver/scoring. Lovlige valg er `legalMoves` filtrert med `applyMove().ok`. Modellen får offentlig brikkeidentitet, egenskaper, hånd, operasjoner, budsjett, egne trekk og lovlige navngitte handlinger. Ingen solution/seed-fasit/solverhint.
- Fast, liten manifest-samling med disjunkte tren/dev/holdout-IDer og innholdshasher; detekter duplikater. Dekk swap/rotate/mirror/hand/locked, sticky i adaptertest. Eksplisitt lavt trekkbudsjett.
- Lokal HTTP-Ollama uten credentials/redirects, strukturert JSON-valg, tidsfrist, fast modell-digest. Ingen verktøy eller shell til modellen. Flere modeller kan kjøres som separate sammenlignbare runmapper; første kjøring bruker Gemma.
- Modellfeil, timeout, avbrudd og uløselig innen budsjett er forskjellige utfall. Ingen skjult fallback. Bare fullførte par brukes ved seleksjon; kandidat må ha streng målbar gevinst og minst like høy løsningsrate. Likhet beholder incumbent.
- Erfaring gir ett kort strategiforslag; samme dev-brett og kallgrenser sammenligner gammel/ny. Holdout fryses, kjøres initial/final én gang etter seleksjon, og påvirker aldri strategi. Rapporter utvalgsstørrelse og begrenset evidens.
- Ignorert `sidecar-runs/` inneholder atomiske checkpoints, fullførte spillspor og lesbar rapport. Eksklusiv lås, STOP/SIGINT/SIGTERM, maksimal tid/kall, kilde-/konfig-/modellidentitet ved resume. Opprinnelig deadline beholdes. Ingen secrets nødvendig.
