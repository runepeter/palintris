# Skrifter

Cinzel og Nunito, variable WOFF2-filer (vekt 400–700), lastet fra Google Fonts 2026-09-20. Latin-utgaven dekker norsk tekst. Nettleseren bruker systemfont for symboler som ikke finnes i skrifttypen.

- [Cinzel-kilde](https://github.com/google/fonts/tree/main/ofl/cinzel) – `Cinzel-OFL.txt`.
- [Nunito-kilde](https://github.com/google/fonts/tree/main/ofl/nunito) – `Nunito-OFL.txt`.

Skriftene serveres lokalt; spillet trenger ingen forespørsler til Google Fonts.
